######  Installatie van Debian 11 (Bullseye) #########
- Stap 1: Debian 11 ISO downloaden

Download Debian 11 via de officiële website:
https://cdimage.debian.org/debian-cd/current/amd64/iso-dvd/

- Stap 2: Virtuele machine aanmaken in Hyper-V

Open Hyper-V Manager
Klik op Nieuwe virtuele machine
Geef de naam: Debian 11 Bullseye
Kies Generatie 2
Stel 4096 MB RAM in
Koppel een virtuele switch
Voorzie 50 GB opslag
Selecteer de gedownloade Debian ISO
Klik op Voltooien

- Stap 3: VM configureren

Rechtsklik op de VM → Instellingen
Ga naar Beveiliging
Selecteer Microsoft UEFI-certificeringsinstantie
Schakel TPM in
Klik op Toepassen en OK

- Stap 4: Debian 11 installeren
Start de VM
Kies Graphical Install
Selecteer taal, land en toetsenbord
Geef hostnaam: debian11
Stel root- en gebruikerswachtwoorden in
Kies schijfindeling (standaard of versleuteld)
Selecteer pakketten
Voltooi de installatie

############# Docker installeren op Debian 11 #######################

- Stap 1: Voorbereiding

Zorg dat je gebruiker sudo-rechten heeft en dat de repositories correct zijn ingesteld.

- Stap 2: Docker Engine installeren

Volg de officiële Docker-documentatie:
https://docs.docker.com/engine/install/debian/

Update het systeem:

sudo apt update
sudo apt upgrade


Installeer Docker:

sudo apt-get install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin


Controleer de installatie:

docker run hello-world

- Stap 3: Gebruiker toevoegen aan Docker-groep
sudo gpasswd -a jiaqi docker
newgrp docker

- Containers aanmaken
Container 1: BusyBox
docker pull busybox
docker run -it -d --name CNTOH1 busybox
docker exec -it CNTOH1 sh

- Container 2: Nginx
docker pull nginx
docker run --name CNTOH2 -p 8080:80 -d nginx
docker exec -it CNTOH2 bash

- Docker-netwerk aanmaken
docker network create NTINTOH
docker network ls

- Container 3: Ubuntu
docker pull ubuntu
docker run -itd --rm --network NTINTOH --name CNTOH3 ubuntu
docker exec -it CNTOH3 sh

- Portainer installeren
docker volume create portainer_data
docker run -d -p 8000:8000 -p 9443:9443 \
--name portainer --restart=always \
-v /var/run/docker.sock:/var/run/docker.sock \
-v portainer_data:/data portainer/portainer-ce:latest
